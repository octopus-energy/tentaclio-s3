# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.5]
### Added
 - Support for Python 3.12, 3.13 and 3.14
 - CI test matrix across Python 3.10 to 3.14
### Changed
 - Set minimum dependency versions: tentaclio>=1.3.6, boto3>=1.27
 - Upgrade moto (dev dependency) to 5.x
 - Publish to PyPI via GitHub Actions instead of CircleCI
### Removed
 - Support for Python 3.9

## [0.0.4] - 2026-02-06
Tagged on GitHub but not published to PyPI.
### Changed
 - Migrate dependency management from pipenv to uv
 - Update AWS dependencies (boto3, botocore, s3transfer) to latest versions

## [0.0.3] - 2022-12-30
### Added
 - Full s3 path included in error message when unable to fetch the remote file

## [0.0.2] - 2022-02-24
### Added
 - Ability to set ACL for put operations

## [0.0.1]
### Added
 - S3 client.
