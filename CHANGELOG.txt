# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.0] - 2026-10-22
### Changed
  - Bump the minimum supported Python from 3.10 (EOL) to 3.11.
  - Add support for Python 3.15.
  - Simplify release process by using dynamic versioning.
### Fixed
  - Raise the `[build-system]` floor from `setuptools>=61.0` to `setuptools>=77`. The
    `license = "MIT"` SPDX string (PEP 639) needs setuptools 77+, so building the sdist with an
    older setuptools and build isolation off failed with an opaque `project.license must be valid
    exactly by one definition` error (https://github.com/octopus-energy/tentaclio/pull/251).
  - Lint changes to pass latest version of mypy.
  - Format using latest version of black.
  - Fix isort & black format incompatibilities.
  - Fix dev dependencies not defined within `[dependency-groups]` block in `pyproject.toml`.

## [0.0.5] - 2026-10-08
### Added
 - Support for Python 3.12, 3.13 and 3.14
 - CI test matrix across Python 3.10 to 3.14
### Changed
 - Set minimum dependency versions: tentaclio>=1.3.6, boto3>=1.27
 - Upgrade moto (dev dependency) to 5.x
 - Publish to PyPI via GitHub Actions instead of CircleCI
### Removed
 - Support for Python 3.9

## [0.0.4] - 2026-02-06
Tagged on GitHub but not published to PyPI.
### Changed
